«УБЕЖИЩЕ» — СЕРВЕР НА КОМПЬЮТЕРЕ ДЛЯ ИГРЫ ЧЕРЕЗ ИНТЕРНЕТ
======================================================

Компьютер работает как игровой сервер, а программа tuna даёт ему адрес
в интернете вида  brave-otter-4821.ru.tuna.am. Друзья могут играть откуда
угодно и без VPN. Пока идёт игра, компьютер должен быть включён.

Для игры в одной Wi-Fi сети компьютер не нужен — там комнату держит телефон.


ПЕРВЫЙ РАЗ (около 10 минут)
---------------------------

1. Установите Node.js
   Откройте https://nodejs.org, выберите версию LTS и скачайте
   «Windows Installer (.msi)». Установите со всеми настройками по умолчанию.

2. Установите tuna
   Скачайте установщик https://releases.tuna.am/tuna/latest/tuna_x64.msi
   и запустите его двойным щелчком (понадобятся права администратора).
   Или в PowerShell:   winget install --id yuccastream.tuna

3. Войдите в tuna
   Зарегистрируйтесь на https://tuna.am, затем откройте командную строку
   (Win+R → cmd) и выполните:   tuna login
   Откроется браузер — подтвердите вход.

4. Постоянный адрес (очень желательно)
   У каждого аккаунта tuna есть один бесплатный постоянный поддомен вида
   brave-otter-4821. Найдите его в личном кабинете tuna.am и впишите
   ОДНОЙ строкой в файл subdomain.txt рядом с этой инструкцией.
   Тогда адрес сервера не меняется, и приложение помнит его всегда.
   Без этого шага адрес будет новым при каждом запуске.

5. Автозапуск (по желанию)
   Двойной щелчок по  autostart-on.bat  — сервер будет запускаться сам
   при входе в Windows, в свёрнутом окне. Выключить: autostart-off.bat.


КАЖДЫЙ РАЗ ПЕРЕД ИГРОЙ
----------------------

1. Двойной щелчок по  start.bat  (если включён автозапуск — уже запущено).
   Откроется одно окно: в нём сервер и туннель. Когда всё готово,
   появится рамка с адресом сервера.
   Пока окно открыто, компьютер не уходит в сон (экран гаснуть может).

2. В приложении: «Создать комнату» → «Через интернет» → в поле
   «Адрес сервера» впишите адрес из рамки. Это нужно один раз:
   приложение запоминает адрес.

3. В лобби нажмите «Пригласить друзей» и отправьте ссылку в Telegram
   или любой мессенджер. Друг открывает ссылку → «Открыть в приложении» —
   код и адрес подставятся сами, останется ввести имя и нажать «Войти».
   Браузер при первом заходе может показать страницу-предупреждение
   tuna — это нормально, нажмите «Продолжить».

Остановка: закройте окно. Идущие партии при этом пропадут.

Проверка: откройте в браузере  https://<ваш адрес>/health
Должно появиться {"ok":true,...}.


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
• «Не найден Node.js» — установите Node.js (шаг 1) и перезагрузите компьютер.
• «Не найдена программа tuna» — установите tuna (шаг 2). Без неё сервер
  работает только в домашней сети.
• «Похоже, tuna не авторизована» — выполните  tuna login  (шаг 3).
• Рамка с адресом не появляется больше минуты — проверьте интернет;
  туннель сам перезапускается каждые 15 секунд.
• Окно сразу закрылось с ошибкой про порт 8080 — порт занят другой
  программой (например, уже открыт второй start.bat); закройте её или
  перезагрузите компьютер.
• В приложении «Нет связи с сервером» — проверьте, что окно сервера открыто
  и адрес в приложении совпадает с адресом из рамки.
