«УБЕЖИЩЕ» — СЕРВЕР НА КОМПЬЮТЕРЕ ДЛЯ ИГРЫ ЧЕРЕЗ ИНТЕРНЕТ
======================================================

Компьютер работает как игровой сервер, а программа tuna даёт ему адрес
в интернете вида  слово-слово-1234.ru.tuna.am. Друзья могут играть откуда
угодно и без VPN. Пока идёт игра, компьютер должен быть включён и оба окна
(сервер и туннель) открыты.

Для игры в одной Wi-Fi сети компьютер не нужен — там комнату держит телефон.


ПЕРВЫЙ РАЗ (около 10 минут)
---------------------------

1. Установите Node.js
   Откройте https://nodejs.org, скачайте версию LTS и установите
   со всеми настройками по умолчанию.

2. Установите tuna
   Скачайте установщик https://releases.tuna.am/tuna/latest/tuna_x64.msi
   и запустите его двойным щелчком (понадобятся права администратора).
   Или в PowerShell:   winget install --id yuccastream.tuna

3. Войдите в tuna
   Зарегистрируйтесь на https://tuna.am, затем откройте командную строку
   (Win+R → cmd) и выполните:   tuna login
   Откроется браузер — подтвердите вход.

4. Узнайте свой бесплатный постоянный поддомен
   У каждого аккаунта tuna есть один бесплатный постоянный адрес вида
   brave-otter-4821 (его выдают случайно, выбрать имя нельзя).
   Найдите его в личном кабинете tuna.am и впишите ОДНОЙ строкой в файл
   subdomain.txt рядом с этой инструкцией, например:
       brave-otter-4821
   Можно и без этого шага, но тогда адрес будет меняться при каждом запуске.


КАЖДЫЙ РАЗ ПЕРЕД ИГРОЙ
----------------------

1. Двойной щелчок по  start-server.bat
   Должно появиться: «сервер работает на порту 8080».

2. Двойной щелчок по  start-tunnel.bat
   В окне появится адрес https://….ru.tuna.am

3. В приложении: «Создать комнату» → «Через интернет» → в поле «Адрес
   сервера» впишите адрес туннеля (без https:// тоже можно).
   Друзьям: «Войти по коду», четыре цифры и тот же адрес сервера.
   Приложение запоминает адрес, вводить его нужно один раз.

Проверка: откройте в браузере  https://<ваш адрес>/health
Должно появиться {"ok":true,...}. Браузер при первом заходе может показать
страницу-предупреждение tuna — это нормально, приложению она не мешает.


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
• «Не найден Node.js» — установите Node.js (шаг 1) и перезапустите компьютер.
• «Не найдена программа tuna» — установите tuna (шаг 2).
• Окно сервера сразу закрылось с ошибкой про порт 8080 — порт занят другой
  программой; закройте её или перезагрузите компьютер.
• В приложении «Нет связи с сервером» — проверьте, что оба окна открыты
  и адрес в приложении совпадает с адресом из окна туннеля.
• Остановка: закройте оба окна. Идущие партии при этом пропадут.
