# Сервер для игры по сети

Сервер хранит комнаты и ведёт партии. Без него работает только «Игра с ботами».

Сервер написан на Node.js без внешних библиотек. Телефоны связываются с ним по обычному HTTP(S) «долгими» запросами, поэтому поддержка WebSocket у хостинга не нужна.

## Где запускать

Нужен хостинг в России: с лета 2025 российские провайдеры замедляют Cloudflare, Hetzner, DigitalOcean, OVH и другие зарубежные площадки, и сетевая игра через них будет зависать.

Ниже — бесплатный запуск на **Render** и платный на **Amvera** (amvera.ru): российская площадка, приложение работает без «засыпания», при регистрации даётся стартовый баланс, дальше — от 170 ₽ в месяц (цены на сентябрь 2026, уточняйте на сайте). Подойдёт и любой другой хостинг с Docker.

## Запуск на Render (бесплатно)

Бесплатный тариф Render: сервер засыпает через 15 минут без игроков и просыпается около минуты; 750 часов в месяц и 5 ГБ трафика. Это зарубежная площадка — из России может работать медленнее.

1. Зайдите на render.com и войдите через GitHub (кнопка «GitHub» при регистрации).
2. Нажмите **New → Blueprint** и выберите репозиторий `bunker-app`. Render прочитает файл `render.yaml` и сам заполнит настройки: Docker, бесплатный тариф, проверка `/health`.
   Если Blueprint недоступен — **New → Web Service**, репозиторий `bunker-app`, Runtime **Docker**, Instance Type **Free**, Health Check Path `/health`.
3. Нажмите **Deploy** и дождитесь статуса **Live** (первая сборка — несколько минут).
4. Вверху страницы сервиса будет адрес вида `https://ubezhishe.onrender.com`. Откройте `<адрес>/health` — должно появиться `{"ok":true,…}`.
5. Впишите адрес в приложение (главный экран → строка «Сервер» внизу) или пришлите его разработчику, чтобы он стал адресом по умолчанию.

Сервер пересобирается сам, когда меняется серверный код в репозитории (`server/`, `src/game/`, `src/data/`, `Dockerfile`). При пересборке и засыпании идущие партии пропадают.

## Запуск на Amvera

1. Зарегистрируйтесь на amvera.ru.
2. Создайте проект: тип «Приложение», любое имя (например, `ubezhishe`), самый простой тариф.
3. Загрузите файлы сервера одним из способов:
   - **через интерфейс** — распакуйте `ubezhishe-server.zip` и загрузите всё его содержимое: `Dockerfile`, `amvera.yml`, папки `server` и `src`;
   - **через git** — Amvera показывает адрес своего git-репозитория; отправьте туда этот репозиторий (`git push`).
4. Дождитесь окончания сборки. Если Amvera спросит окружение — выберите Docker, порт контейнера `80`.
5. Во вкладке с доменами включите бесплатный домен вида `ubezhishe-….amvera.io`.
6. Проверьте: откройте в браузере `https://<ваш домен>/health`. Должно появиться `{"ok":true,…}`.
7. В приложении на главном экране нажмите на строку «Сервер…» внизу и вставьте адрес домена. Его же сообщите друзьям — или пришлите мне, и я впишу его в приложение по умолчанию.

## Запуск на своём компьютере (игра в одной Wi-Fi сети)

С Docker:

```
docker build -t ubezhishe .
docker run -p 8080:80 ubezhishe
```

Без Docker (нужен Node.js 22):

```
npm install -g typescript@6.0.3
npm install --no-save @types/node@22
cd server && tsc -p tsconfig.json --typeRoots ../node_modules/@types && cd ..
PORT=8080 node server/dist/server/server.js
```

В приложении укажите адрес с `http://` и IP компьютера в сети, например `http://192.168.1.10:8080`. Компьютер должен разрешать входящие подключения на этот порт.

## Как устроено

- `src/game/engine.ts` — правила партии; `src/game/actions.ts` — действия игроков и ведущего; `src/game/room.ts` — лобби и выбор ведущего. Этот же код работает в одиночной игре на телефоне.
- `server/server.ts` — HTTP-сервер, комнаты хранятся в памяти. При перезапуске сервера идущие партии пропадают.
- Комната закрывается сама через 3 часа без активности.

| Запрос | Что делает |
|---|---|
| `POST /api/rooms` `{ name, settings }` | создать комнату, ответ `{ code, playerId, token }` |
| `POST /api/rooms/:code/join` `{ name }` | войти по коду |
| `POST /api/rooms/:code/action` `{ token, action }` | действие игрока или ведущего |
| `GET /api/rooms/:code/state?token=…&since=N` | состояние комнаты; ждёт изменений до 20 секунд |
| `GET /health` | проверка, что сервер жив |
