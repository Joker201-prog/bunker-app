# Игра по сети

В приложении два способа сетевой игры. Правила, лобби и ведущий в них одинаковые.

| | В этой Wi-Fi сети | Через интернет |
|---|---|---|
| Кто держит комнату | телефон, создавший комнату | игровой сервер на Amvera (адрес встроен в приложение) |
| Где могут быть игроки | рядом, в одной Wi-Fi сети или на точке доступа телефона | где угодно |
| Код комнаты | 5 цифр | 4 цифры |
| Что нужно | ничего | только интернет; друзья входят по ссылке-приглашению или коду |

Зарубежные бесплатные хостинги (Render и подобные) из России без VPN не открываются, поэтому сервер работает на российском хостинге Amvera: `https://ubezhishe-poplavok.msk1.amvera.tech`. Адрес задан в `DEFAULT_SERVER` (`src/net/api.ts`); в приложении игрок его не видит и не вводит.

**Обновление сервера.** Логика комнат работает на сервере, поэтому после изменений в `src/game/`, `src/server/` или `server/` сервер на Amvera нужно пересобрать из свежего кода (`Dockerfile`, `amvera.yml`, папки `server` и `src`). Страница приглашения `/j/<код>` появилась в 0.9.1 — до обновления сервера ссылка из приглашения не откроется, но вход по коду работает.

## В этой Wi-Fi сети

1. Ведущий: «Создать комнату» → «В этой Wi-Fi сети». Телефон запускает сервер и показывает пятизначный код.
2. Остальные подключаются к той же Wi-Fi сети (или к точке доступа телефона ведущего) и вводят код в «Войти по коду».
3. Первые три цифры кода — последнее число адреса телефона в сети, поэтому другой телефон обычно находит комнату сразу. Если не нашёл — перебирает все адреса своей сети (несколько секунд).

Ограничения: у телефона-сервера приложение должно быть открыто, экран не гаснет сам. Если ведущий выйдет из комнаты или закроет приложение, партия закончится у всех.

## Запасной вариант: сервер на компьютере + tuna

Приложение с 0.9.1 подключается только к встроенному серверу, поле адреса убрано. Пакет для компьютера оставлен в репозитории на случай переезда сервера: чтобы снова им пользоваться, нужно поменять `DEFAULT_SERVER` и собрать приложение.

Готовый пакет — `ubezhishe-pc-server.zip` (собирается командой `bash tools/make_pc_server.sh`). Внутри:

- `start.bat` — одно окно: сервер на порту 8080 + туннель `tuna http 8080` (с постоянным поддоменом из `subdomain.txt`, если он указан); показывает адрес сервера в рамке, перезапускает туннель при обрыве и не даёт компьютеру уснуть, пока окно открыто;
- `autostart-on.bat` / `autostart-off.bat` — включить или выключить запуск сервера при входе в Windows;
- `README.txt` — пошаговая инструкция на русском.

Коротко:

1. Установить Node.js (https://nodejs.org, версия LTS) и tuna (`winget install --id yuccastream.tuna` или установщик с tuna.am).
2. Выполнить `tuna login`.
3. Вписать бесплатный постоянный поддомен (вида `brave-otter-4821`) в `subdomain.txt`.
4. Перед игрой запустить `start.bat` (или один раз включить автозапуск).
5. В приложении: «Создать комнату» → «Через интернет» → адрес `brave-otter-4821.ru.tuna.am`.
6. В лобби — «Пригласить друзей»: уходит ссылка `https://<адрес>/j/<код>`. Страница по ссылке открывает приложение (`ubezhishe://join?server=…&code=…`) с подставленными адресом и кодом.

Проверка: `https://<адрес>/health` → `{"ok":true,…}`.

## Другие способы запустить сервер

- **Docker:** `docker build -t ubezhishe . && docker run -p 8080:8080 ubezhishe`.
- **Хостинг в России с Docker** (например, Amvera): загрузить `Dockerfile`, `amvera.yml`, папки `server` и `src`. Порт контейнера — 8080.
- `render.yaml` описывает сервер для Render; из России без VPN он недоступен.

## Как устроено

- `src/game/` — правила, действия игроков и ведущего, лобби. Один и тот же код в одиночной игре, на телефоне-сервере и на компьютере.
- `src/server/core.ts` — сервер без привязки к платформе: комнаты, сессии, «долгие» запросы.
- `src/server/httpOverTcp.ts` — HTTP поверх TCP для телефона (модуль `react-native-tcp-socket`).
- `src/server/lanCode.ts` — пятизначные коды и порядок поиска комнаты в сети.
- `server/server.ts` — сервер для компьютера на встроенном `http` Node.

| Запрос | Что делает |
|---|---|
| `POST /api/rooms` `{ name, settings }` | создать комнату → `{ code, playerId, token }` |
| `POST /api/rooms/:code/join` `{ name }` | войти по коду |
| `POST /api/rooms/:code/action` `{ token, action }` | действие игрока или ведущего |
| `GET /api/rooms/:code/state?token=…&since=N` | состояние; ждёт изменений до 20 секунд |
| `GET /api/rooms/:code/ping` | есть ли комната (для поиска в сети) |
| `GET /health` | сервер жив |
