# Убежище — мобильная игра в духе «Бункера»

React Native (Expo) + TypeScript. Два режима:

- **Игра с ботами** — на одном телефоне, без интернета.
- **В этой Wi-Fi сети** — комнату держит телефон ведущего, остальные входят по пятизначному коду. Ничего настраивать не нужно.
- **Через интернет** — сервер на компьютере и туннель tuna (запуск одним файлом `start.bat`), вход по ссылке-приглашению из лобби или по четырёхзначному коду. См. [SERVER.md](SERVER.md).

Карты — из библиотеки `content/bunker-library.md`: 76 катастроф в 8 группах и по 100 профессий, вариантов биологии, состояний здоровья, фобий, черт характера, хобби, фактов, предметов багажа и особых условий. Код карт генерируется из неё командой `python3 tools/import_library.py`, проверка библиотеки на повторы и ошибки — `python3 tools/check_library.py content/bunker-library.md`.

## Ведущий

При создании комнаты выбирается, кто ведёт партию:

- **создатель комнаты** — роль можно передать другому игроку в лобби;
- **случайный игрок** — жребий при старте;
- **голосование** — в лобби каждый голосует, кто будет вести.

Отдельно задаётся, **играет ли ведущий сам** (получает карты и голосует) или только ведёт.

Ведущий переводит партию по этапам: стол → обсуждение → голосование → итоги → следующий раунд, запускает и продлевает таймеры обсуждения и голосования, пропускает ход задержавшегося игрока, подсчитывает голоса досрочно и возвращает всех в лобби после финала. За столом карты раскрывают по очереди, журнал раунда показывает, кто что открыл; кто не успел раскрыть карту до обсуждения, получает раскрытую автоматически; когда все проголосовали, голоса подсчитываются сами. Если игрок уходит посреди партии, за него доигрывает бот; если уходит ведущий, роль переходит другому игроку.

В главном меню есть раздел **«Информация»**: все карты и события библиотеки с поиском и фильтром событий по группам. В досье других игроков можно оставлять личные заметки — они хранятся только на своём телефоне.

## Сборка APK

Каждый push в ветку `main` запускает GitHub Actions (`.github/workflows/build-apk.yml`): создаётся проект Expo SDK 54, в него копируются `src/`, `assets/` и `App.tsx`, собирается release-APK и публикуется выпуск `build-N`. Описание выпуска берётся из `release-notes.md` (`{{BUILD}}` и `{{TAG}}` подставляются при сборке). Push в ветку `preview` собирает тестовую сборку — предварительный выпуск `preview-N`, чтобы проверить APK до выхода в `main`. Сборку можно запустить вручную: Actions → Build APK → Run workflow.

## Структура

- `content/bunker-library.md` — библиотека карт и событий; `src/data/library.ts` — сгенерированный из неё код (не править вручную).
- `src/data/cards.ts` — порядок и подписи видов карт, названия тем, карты бункера.
- `src/game/engine.ts` — правила: раздача, раунды, боты, голосование, финал.
- `src/game/actions.ts` — действия игроков и ведущего, таймер, что видит каждый игрок.
- `src/game/room.ts` — лобби, выбор и передача роли ведущего.
- `src/server/` — сервер комнат (общий для телефона и компьютера), HTTP поверх TCP, коды комнат в Wi-Fi.
- `src/net/` — связь с сервером, поиск комнаты в сети, ссылки-приглашения (`invite.ts`); `src/hooks/useLocalGame.ts` — одиночная игра.
- `src/screens/` — меню, «Информация», лобби, игровой экран, финал; `src/hooks/useNotes.ts` — личные заметки; `src/components/` — досье, листы, штампы, изолента.
- `server/server.ts` — сервер для компьютера, `server/launcher.ts` — запуск вместе с туннелем и запретом сна; `pc-server/` и `tools/make_pc_server.sh` — пакет с запуском двойным щелчком.
- `tools/make_textures.py` — генерация текстур дерева, бумаги, силуэтов.

## Проверка

```
tsc -p tsconfig.engine.json --types node
node scripts/simulate.js     # 3000 одиночных партий
node scripts/room-test.js    # лобби, ведущий, сетевые действия
node scripts/lan-test.js     # сервер «в этой сети»: HTTP поверх TCP
cd server && tsc -p tsconfig.json && cd .. && node scripts/server-test.js   # сервер по HTTP
```

## Правила

- 4–16 игроков, мест в бункере вдвое меньше. 5 раундов: стол, обсуждение, голосование.
- У каждого 9 карт: профессия, биология, здоровье, фобия, характер, хобби, факт, багаж, особое условие.
- Раунд 1 — все раскрывают профессию; дальше каждый раскрывает одну карту на выбор. Нажатие на открытую карту показывает её полное описание.
- Особые условия исполняет ведущий по тексту карты; «Дополнительный голос» приложение учитывает само.
- Финал считается по правилам: полезность карт выживших + бонусы бункера + закрыты ли три главные нужды катастрофы; чем выше сложность катастрофы, тем больше нужно набрать.
