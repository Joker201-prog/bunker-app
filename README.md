# Убежище — мобильный прототип игры «Бункер»

Прототип на React Native (Expo) + TypeScript. Игра против ботов, без сервера.
Карты, катастрофы и бункеры — собственные.

## Сборка APK
Каждый push в ветку `main` запускает GitHub Actions (`.github/workflows/build-apk.yml`): создаётся проект Expo SDK 54, в него копируются `src/` и `App.tsx`, собирается release-APK. Готовый файл появляется во вкладке Releases. Сборку можно запустить вручную: Actions → Build APK → Run workflow.

## Запуск в Expo Go
1. Создайте проект Expo: `npx create-expo-app@latest bunker --template blank-typescript`
2. Скопируйте папку `src/` из этого архива в проект и замените `App.tsx` на файл из архива.
3. `npx expo start`, затем откройте в Expo Go на телефоне.

Код использует только `react` и `react-native` без дополнительных библиотек.

## Структура
- `src/data/cards.ts` — все карты (профессии, здоровье, факты, хобби, багаж, особые условия), катастрофы, карты бункера.
- `src/game/engine.ts` — правила: раздача, раунды, боты, голосование, финал.
- `src/screens/` — главная, игровой экран (стол, обсуждение, голосование, итоги), финал.
- `scripts/simulate.js` — симуляция 3000 партий с ботами для проверки правил.

## Проверка движка
`npx tsc -p tsconfig.engine.json && node scripts/simulate.js`

## Правила прототипа
- 4–16 игроков, мест в бункере вдвое меньше. 5 раундов: стол, обсуждение (60 с), голосование.
- Раунд 1 — все раскрывают профессию; дальше каждый раскрывает одну карту на выбор.
- Особые условия: «Двойной голос» и «Неприкосновенность» (одно спасение от исключения).
- Финал считается по правилам: очки карт выживших + бонусы бункера + закрыты ли нужды катастрофы.
