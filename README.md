# Убежище — мобильная игра в духе «Бункера»

React Native (Expo) + TypeScript. Два режима:

- **Игра с ботами** — на одном телефоне, без интернета.
- **В этой Wi-Fi сети** — комнату держит телефон ведущего, остальные входят по пятизначному коду. Ничего настраивать не нужно.
- **Через интернет** — сервер на компьютере и туннель tuna, вход по четырёхзначному коду. См. [SERVER.md](SERVER.md).

Карты, катастрофы и бункеры — собственные.

## Ведущий

При создании комнаты выбирается, кто ведёт партию:

- **создатель комнаты** — роль можно передать другому игроку в лобби;
- **случайный игрок** — жребий при старте;
- **голосование** — в лобби каждый голосует, кто будет вести.

Отдельно задаётся, **играет ли ведущий сам** (получает карты и голосует) или только ведёт.

Ведущий переводит партию по этапам: стол → обсуждение → голосование → итоги → следующий раунд, может добавить время к обсуждению, подсчитать голоса досрочно и вернуть всех в лобби после финала. Кто не успел раскрыть карту, получает раскрытую автоматически; когда все проголосовали, голоса подсчитываются сами. Если игрок уходит посреди партии, за него доигрывает бот; если уходит ведущий, роль переходит другому игроку.

## Сборка APK

Каждый push в ветку `main` запускает GitHub Actions (`.github/workflows/build-apk.yml`): создаётся проект Expo SDK 54, в него копируются `src/`, `assets/` и `App.tsx`, собирается release-APK. Готовый файл появляется во вкладке Releases. Сборку можно запустить вручную: Actions → Build APK → Run workflow.

## Структура

- `src/data/cards.ts` — карты, катастрофы, карты бункера.
- `src/game/engine.ts` — правила: раздача, раунды, боты, голосование, финал.
- `src/game/actions.ts` — действия игроков и ведущего, таймер, что видит каждый игрок.
- `src/game/room.ts` — лобби, выбор и передача роли ведущего.
- `src/server/` — сервер комнат (общий для телефона и компьютера), HTTP поверх TCP, коды комнат в Wi-Fi.
- `src/net/` — связь с сервером и поиск комнаты в сети; `src/hooks/useLocalGame.ts` — одиночная игра.
- `src/screens/` — меню, лобби, игровой экран, финал; `src/components/` — досье, листы, штампы, изолента.
- `server/server.ts` — сервер для компьютера; `pc-server/` и `tools/make_pc_server.sh` — пакет с запуском двойным щелчком.
- `tools/make_textures.py` — генерация текстур дерева, бумаги, силуэтов.

## Проверка

```
tsc -p tsconfig.engine.json --types node
node scripts/simulate.js     # 3000 одиночных партий
node scripts/room-test.js    # лобби, ведущий, сетевые действия
node scripts/lan-test.js     # сервер «в этой сети»: HTTP поверх TCP
cd server && tsc -p tsconfig.json && cd .. && node scripts/server-test.js   # сервер по HTTP
```

## Правила

- 4–16 игроков, мест в бункере вдвое меньше. 5 раундов: стол, обсуждение, голосование.
- Раунд 1 — все раскрывают профессию; дальше каждый раскрывает одну карту на выбор.
- Особые условия: «Двойной голос» и «Неприкосновенность» (одно спасение от исключения).
- Финал считается по правилам: очки карт выживших + бонусы бункера + закрыты ли нужды катастрофы.
